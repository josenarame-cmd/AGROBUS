## Directory Structure

```
dataset/phase2/
├── raw/
│   ├── images/        ← Place original soil photographs here (RW-SOIL-XXXX-YY.jpg)
│   └── laboratory/    ← Place raw laboratory CSV exports here (one per batch)
│
├── metadata/
│   └── samples.csv    ← Master dataset (headers created, no data yet)
│
├── processed/         ← Generated by prepare pipeline after validation passes
│
├── quarantine/        ← Records moved here by validator — do NOT manually delete
│
└── README.md          ← This file
```

---

## How To Add Data

1. Follow the field collection protocol:
   `docs/phase2/PHASE_2_3_FIELD_COLLECTION_CHECKLIST.md`

2. Place images in:
   `dataset/phase2/raw/images/`

3. Place laboratory CSV in:
   `dataset/phase2/raw/laboratory/`

4. Populate:
   `dataset/phase2/metadata/samples.csv`
   with real values — DO NOT invent measurements.

5. Run the validator:
   ```
   python dataset/phase2/validate_dataset.py
   ```

6. If validator passes: proceed to Phase 2.4.
   If validator fails: fix issues, re-run, do not proceed until passing.

---

## Rules

- NEVER populate samples.csv with invented, estimated, or fabricated values.
- NEVER place unlinked images in raw/images/ without a corresponding samples.csv row.
- NEVER place laboratory results in raw/laboratory/ without matching Sample IDs.
- NEVER delete from quarantine/ without documenting the reason.
- ALWAYS run the validator before declaring Phase 2.3 complete.
